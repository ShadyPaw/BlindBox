## 近期未完成事项

- 33 款消费盲盒、17 款金币盲盒的完整物品清单和说明；继续明确显示资料缺口。
- 字体、图标、部分素材、间距和桌面／手机逐页视觉对照，尚未达到完整 1:1 验收。
- 完整个人中心、空投、背包等登录后业务页面。
- 输入要求、注册按钮禁用原因及异常文案的醒目程度和交互优化。已有基础提示不代表该专项已验收。
- 正式政策文章、语言选单、活动内容和客服交互。
- 邮箱所有权验证与生产 SMTP 投递验收；当前注册邮箱不能视为已验证。
- 生产 TLS、密钥管理、可信代理及真实客户端 IP 限流、监控、备份恢复和部署回滚。当前 Web 代理下的 API IP 配额由代理用户共享。
- Docker 容器本机运行验收和完整线上部署；不能用本地测试通过代替生产验收。
